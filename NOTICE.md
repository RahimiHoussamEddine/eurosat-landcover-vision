# Data and attribution

EuroSAT RGB is licensed under MIT by Patrick Helber, Benjamin Bischke, Andreas
Dengel, and Damian Borth. The source images are based on Copernicus Sentinel-2
data. This project retains the required attribution and asks users to review
the [Copernicus Sentinel Data Terms](https://sentinel.esa.int/documents/247904/690755/Sentinel_Data_Legal_Notice).
The image archive is not included in this repository; downloaded data are
ignored by Git.

Dataset: <https://zenodo.org/records/7711810> (EuroSAT RGB, version 2).
Dataset paper: Helber et al., “EuroSAT: A Novel Dataset and Deep Learning
Benchmark for Land Use and Land Cover Classification,” 2019,
<https://arxiv.org/abs/1709.00029>.
